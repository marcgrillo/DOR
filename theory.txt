\subsection{Probabilistic framework}
The methodology takes as the DM's information a ranking on a set of reference alternatives. To strictly capture preference intensity we formulate the likelihood via a Cumulative Link Model. The number of blank cards $\eta(a_i,a_j) \in \{0, 1, \dots, \eta_{max}\}$ acts as an explicit ordinal target variable.  Let $z_\tau = \boldsymbol{x}_\tau^\top \boldsymbol{w}$ be the latent, continuous utility difference between two alternatives, where $\boldsymbol{x}_\tau = \boldsymbol{v}(a_i) - \boldsymbol{v}(a_j)$. We introduce a threshold vector $\boldsymbol{\theta} = (\theta_0, \theta_1, \dots, \theta_{\eta_{max}})$ subject to the strict monotonic constraint:

\begin{equation}
0 \equiv \theta_0 \le \theta_1 \le \dots \le \theta_{\eta_{max}} < \theta_{\eta_{max}+1} \equiv \infty
\end{equation}  

To enforce this strict ordering while preserving a log-concave parameter space, we reparameterize $\boldsymbol{\theta}$ using a set of strictly positive increments $\boldsymbol{\Delta} = (\Delta_1, \dots, \Delta_{\eta_{max}}) \in \mathbb{R}^{\eta_{max}}_+$, such that $\theta_k = \sum_{m=1}^k \Delta_m$. The probability that the DM places exactly $\eta_\tau$ cards between $a_i$ and $a_j$ is the probability that the latent utility difference $z_\tau$ falls precisely within the continuous interval $[\theta_{\eta_\tau}, \theta_{\eta_\tau+1})$. Using the logistic cumulative distribution function $\sigma(z) = (1 + e^{-z})^{-1}$, this is computed as the difference between two CDFs:

\begin{equation}\label{eq:ordered_logit}P(\eta_\tau | \boldsymbol{x}_\tau, \boldsymbol{w}, \boldsymbol{\Delta}) = \sigma\left(\sum_{m=1}^{\eta_\tau+1} \Delta_m - \boldsymbol{x}_\tau^\top \boldsymbol{w}\right) - \sigma\left(\sum_{m=1}^{\eta_\tau} \Delta_m - \boldsymbol{x}_\tau^\top \boldsymbol{w}\right)
\end{equation}

\subsection{Bayesian framework}
\label{sec:method_bayes}
We collect new information in different sequential elicitation steps $t$. The active learning algorithm, at each step, selects a subset $S_t \subset A$ of cardinality $|S_t| = k$. Repetitions across steps are permitted, meaning $S_t \cap S_{t'} \neq \emptyset$ is valid.  The Decision Maker (DM) is tasked with providing a full ranking of $S_t$ and adding blank cards to indicate preference intensity. This action yields a ranking configuration $R_t$. From $R_t$, we extract the set of all implicitly generated pairwise comparisons, denoted as $Q_t$. Because $R_t$ is a complete order over $k$ elements, $Q_t$ contains exactly $\binom{k}{2}$ unique preference relations. Each element $q_\tau \in Q_t$ is defined as a tuple $q_\tau = \left(a_{i_\tau}, a_{j_\tau}, \eta_\tau\right)$.  Under the assumption of conditional independence among the pairwise comparisons within a given subrank, the probability of observing the configuration $R_t$ given the expanded parameter space $\Phi = (\boldsymbol{w}, \boldsymbol{\Delta})$ is:

\begin{equation}P(R_t | \boldsymbol{w}, \boldsymbol{\Delta}) = \prod_{q_\tau \in Q_t} \left[ \sigma\left(\theta_{\eta_\tau+1} - \boldsymbol{x}_\tau^\top \boldsymbol{w}\right) - \sigma\left(\theta_{\eta_\tau} - \boldsymbol{x}_\tau^\top \boldsymbol{w}\right) \right]
\end{equation}

To guarantee log-concavity for the theoretical bounds, we assign independent Gamma priors to both the utility weights and the threshold increments:

\begin{equation}
\pi(\boldsymbol{w}, \boldsymbol{\Delta}) = \prod_{i=1}^N \text{Gamma}(w_i | \alpha, \beta) \prod_{m=1}^{\eta_{max}} \text{Gamma}(\Delta_m | \alpha_\theta, \beta_\theta)
\end{equation}

where $\boldsymbol{w} \in \mathbb{R}^N_{+}$ is unconstrained above zero, and $\alpha, \alpha_\theta \ge 1$.  Given a sequence of independent queries $S_1, \dots, S_T$ and corresponding observed configurations $R_1, \dots, R_T$, the joint likelihood is:

\begin{equation}
\label{eq:likelihood}
\mathcal{L}({Q_1, \dots, Q_T} | \boldsymbol{w}, \boldsymbol{\Delta}) = \prod_{t=1}^T P(R_t | \boldsymbol{w}, \boldsymbol{\Delta})
\end{equation}  

Applying Bayes' theorem, the unnormalized posterior distribution over the parameters at step $T$ is:

\begin{equation}
\label{eq:posterior}
p(\boldsymbol{w}, \boldsymbol{\Delta} | \mathcal{D}_T) \propto \mathcal{L}({Q_1, \dots, Q_T} | \boldsymbol{w}, \boldsymbol{\Delta}) \pi(\boldsymbol{w}, \boldsymbol{\Delta})
\end{equation}
